# Deferred scope

V1 targets one privately provisioned workspace with multiple Instagram accounts, specific-post comment campaigns, inbound DM campaigns, and one text resource reply.

Potential later work, after real-account pilot validation:

- All-future-post campaigns and broader media history, with explicit targeting rules.
- Public signup, tenant administration, teams, roles, credential revocation UI, retention/deletion tooling, signed updates, and notarized installers.
- Larger-volume reporting rollups and adaptive provider usage-header throttling.
- TikTok integration only after business-account eligibility, region, review, Comment-to-Message, and webhook contracts are verified for the actual app.
- Optional integrations, richer resource management, and exports based on demonstrated user demand.

No V1 flowcharts, AI agents/replies, multi-message sequences, public auto-comments, inbox replacement, CRM pipelines, email marketing, billing/Stripe, Shopify, or PostHog integration. These are not hidden behind unfinished buttons.
